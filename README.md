# Mbauro Homebrew Tap

Homebrew formulae maintained for Age of Agents.

## Age of Agents Hooks

```bash
brew install Mbauro/tap/age-of-agents-hooks
age-of-agents-hooks install
```

The installer prompts for the Age of Agents server URL and the one-time pairing
code displayed by the game. See the
[hooks documentation](https://github.com/Mbauro/age-of-agents-hooks) for setup,
security, and uninstall details.
